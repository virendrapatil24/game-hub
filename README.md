# Game Hub 🎮

A modern React application that showcases various games and gaming-related information using external APIs. Built with React, TypeScript, and Chakra UI for a beautiful and responsive user interface.

## Features ✨

- Modern and responsive UI using Chakra UI
- Game information display
- Search functionality
- Game details and ratings
- Clean and intuitive user interface

## Tech Stack 🛠️

- React 18
- TypeScript
- Vite
- Chakra UI
- Axios for API calls
- React Icons
- Framer Motion for animations

## Prerequisites 📋

Before you begin, ensure you have the following installed:

- Node.js (v14 or higher)
- npm or yarn package manager

## Installation 🚀

1. Clone the repository:

```bash
git clone https://github.com/yourusername/game-hub.git
cd game-hub
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm run dev
# or
yarn dev
```

The application will be available at `http://localhost:5173`

## Available Scripts 📜

- `npm run dev` - Starts the development server
- `npm run build` - Builds the app for production
- `npm run preview` - Preview the production build locally
